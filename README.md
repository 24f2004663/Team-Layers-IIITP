# 🚀 Life-GPS
### Agentic AI Operating System for Personalized Growth

> **Life-GPS** is an AI-powered personal operating system that understands **who you are, how you behave, where your gaps are, and what you should do next**. Instead of recommending random courses or tasks, Life-GPS continuously analyzes your identity, behavior, goals, and progress to create an adaptive roadmap toward your future self.

---

# 🌟 Vision

Most learning platforms answer:

> **"What should I learn?"**

Life-GPS answers:

> **"Given who you are today and who you want to become, what is the single best thing you should do next?"**

Life-GPS combines AI agents, behavioral intelligence, decision engines, planning, and continuous learning into one unified system.

# 🧠 AI Pipeline

Life-GPS consists of **8 specialized AI agents** working together.

## 1. Identity Agent

Discovers

- Personal mission
- Goals
- Strengths
- Weaknesses
- Interests
- Core values
- Career direction

---

## 2. Behavior Agent

Tracks

- Daily habits
- Productivity
- Focus
- Learning consistency
- Behavioral drift
- Pattern stability

---

## 3. Gap Analysis Agent

Detects

- Knowledge gaps
- Skill gaps
- Motivation gaps
- Execution gaps
- Confidence gaps

---

## 4. Decision Engine

Reasons over

- Identity
- Behavior
- Gap Analysis

Produces

- Priority Graph
- Strategy Selection
- Future Simulations
- Decision Trace

---

## 5. Mission Engine

Transforms decisions into

- Missions
- Objectives
- Success Criteria
- Execution Units

---

## 6. Planner Agent

Schedules

- Daily plans
- Weekly plans
- Energy-aware planning
- Adaptive rescheduling

---

## 7. Curator Agent

Builds personalized learning bundles from

- YouTube
- GitHub
- Books
- Research Papers
- Courses
- Hackathons
- Projects

---

## 8. Learning Loop Agent

Measures

- Growth
- Learning effectiveness
- Resource quality
- Personal Growth Index
- Future simulator calibration

# 🚀 Running Backend

```bash
cd backend

python -m venv .venv

source .venv/bin/activate

pip install -r requirements.txt

uvicorn app.main:app --reload --port 9000
```

Swagger

```
http://localhost:9000/docs
```
